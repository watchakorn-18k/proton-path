# Proton Path — เว็บไซต์ช่อง YouTube สายเดินป่า

เว็บไซต์ประกอบช่อง YouTube **Proton Path** (เนื้อหา: เดินป่า / trekking / outdoor)
สร้างด้วย [Astro](https://astro.build)

---

## แนวคิดเว็บ (Concept)

เว็บควรให้ความรู้สึก **สะอาด เงียบ สงบ** เหมือนอยู่กลางป่า ไม่รก ไม่ฉูดฉาด
เน้นรูปภาพ/วิดีโอเส้นทางเดินป่าเป็นพระเอก ตัวเว็บทำหน้าที่เป็น "กรอบ" ที่ไม่แย่งความสนใจ

หลักการ:
- **Minimal** — พื้นที่ว่างเยอะ (whitespace) ปล่อยให้ภาพธรรมชาติพูดแทน
- **Content-first** — วิดีโอและรูปเส้นทางอยู่หน้าสุด
- **อ่านง่ายบนมือถือ** — คนดูคลิปเดินป่าส่วนใหญ่มาจากมือถือ

---

## ธีม / สไตล์ (Theme)

อิงจากโลโก้: **พื้นขาว ตัวอักษรดำ** → ฐานเว็บเป็น monochrome ขาว-ดำ
แล้วเสริมสีธรรมชาติเป็น accent เล็กน้อยให้ได้อารมณ์ป่าเขา

### โทนสี (Color Palette)

| บทบาท | สี | ค่า | ใช้ตรงไหน |
| :--- | :--- | :--- | :--- |
| พื้นหลัก | ขาว | `#FFFFFF` | background หลัก |
| ตัวอักษร | ดำ | `#111111` | หัวข้อ / เนื้อความ |
| Accent หลัก | เขียวป่า | `#2F5D3A` | ปุ่ม / ลิงก์ / เส้นคั่น |
| Accent รอง | น้ำตาลดิน | `#7A5C3E` | ไอคอน / รายละเอียดเล็ก |
| เทาอ่อน | เทา | `#F2F2F2` | พื้นการ์ด / section สลับ |

> ใช้สีดำ-ขาวเป็นหลัก (~80%) สีเขียว/น้ำตาลเป็น accent (~20%) เท่านั้น อย่าใส่สีเยอะ

### ตัวอักษร (Typography)

- **หัวข้อ:** ฟอนต์ sans-serif หนา คม (เช่น Inter, Sora, Space Grotesk) → ให้ความรู้สึกโมเดิร์น สะอาด ตรงกับโลโก้
- **เนื้อความ:** sans-serif อ่านสบายตา รองรับภาษาไทย (เช่น IBM Plex Sans Thai, Noto Sans Thai)
- เว้นระยะบรรทัดเยอะ ให้โล่ง

### ภาพ (Imagery)

- รูปเส้นทางเดินป่า / ภูเขา / ป่า ความละเอียดสูง เต็มความกว้าง (full-bleed)
- ใช้ภาพจริงจากคลิป ไม่ใช้ stock ที่ดูปลอม
- ไอคอนแบบเส้น (line icon) บางๆ สีดำ

## โครงสร้างหน้าเว็บ (Layout)

1. **Hero** — โลโก้ Proton Path + รูป/วิดีโอป่าเต็มจอ + ปุ่ม "ดูช่อง YouTube"
2. **คลิปล่าสุด** — กริดวิดีโอจาก YouTube (thumbnail + ชื่อคลิป)
3. **เส้นทาง / Trails** — รวมเส้นทางเดินป่าที่เคยรีวิว (ชื่อ + ระดับความยาก + ลิงก์คลิป)
4. **เกี่ยวกับ** — ช่องนี้คือใคร ทำอะไร
5. **Footer** — ลิงก์ YouTube + โซเชียล + ติดต่อ
